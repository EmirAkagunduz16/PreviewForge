# M9 local demo fixtures

This directory is a deterministic, credential-free GitHub/App fixture for the
local product journey. It is not a real repository credential store and it is
never used as a production image source.

Validate the fixture before a run:

```bash
node scripts/m9/fixtures/manifest.mjs --check
```

The fixture server in `scripts/m9/github-fixture.mjs` implements the smallest
GitHub HTTP surface needed by sign-in, App installation, repository import,
source acquisition, and Check Run feedback. It binds to loopback only and
accepts synthetic tokens generated by the process; no token or private key is
stored here.

The repository source is one HTTP application with `/health` and `/` routes.
All Kubernetes and registry identities use the ownership prefixes in the
manifest so a later acceptance runner can prove exact teardown and rerun
safety.

The complete browser/runtime acceptance remains a separate step. A fixture
manifest passing is not evidence that PostgreSQL, Kafka, BuildKit, kind,
Envoy, API, worker, and browser boundaries are healthy.
